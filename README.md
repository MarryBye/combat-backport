# Combat Backport

[![Minecraft 1.7.10](https://img.shields.io/badge/Minecraft-1.7.10-blue.svg)](https://minecraft.net/)
[![Forge](https://img.shields.io/badge/Forge-10.13.4.1614-orange.svg)](https://files.minecraftforge.net/)

**Combat Backport** — модификация для Minecraft 1.7.10 на базе сборочного стека GTNH (RetroFuturaGradle / UniMixins), полностью переносящая современные боевые механики (Minecraft 1.9+ Combat Update) в версию 1.7.10.

**Авторы:** `MarryBye` + `Gemini AI`

---

## 🎯 Реализованные возможности

- ⚔️ **Кулдаун атак (Attack Cooldown) и скорость оружия:**
  - Расчет времени перезарядки для всех ванильных и модовых инструментов и оружия (мечи, топоры, кирки, лопаты, мотыги, кулаки).
  - Сбалансированная базовая скорость кулаков/предметов ($2.5$ / 8 тиков = 0.4 сек), предотвращающая мгновенный набор КД при спам-клике.
  - Поддержка материалов для топоров (дерево/камень 0.8, железо 0.9, алмаз/золото 1.0) и мотыг (1.0–4.0).
  - Универсальная система эвристик для любого оружия из сторонних модов (рапиры, кинжалы, боевые топоры, косы, молоты, копья и др.).
  - Динамическая поддержка оружия из **Tinkers' Construct (GTNH TiC)**: Broadsword, Longsword, Rapier, Dagger, Cutlass, Cleaver, Battleaxe, Scythe, Frypan, Battlesign и др.
  - Отображение показателя **Скорости атаки (Attack Speed)** во всплывающих подсказках (тултипах) оружия и инструментов под строкой урона в стиле ванильного Minecraft 1.9+.
  - Сброс кулдауна при смене предмета в хотбаре и при ударе по воздуху (промахе).
  - Возможность ручного переопределения скорости и урона через конфигурационный файл.

- 🛡️ **Щиты (Shields 1.9+):**
  - Полноценный крафт щита (6 досок любого типа + 1 железный слиток).
  - Блокирование ПКМ с переднего сектора ($180^\circ$ обзор), поглощающее 100% входящего урона и рикошетящее стрелы и снаряды.
  - Отключение щита топором на 5 секунд (100 тиков) с шансом $25\% + 5\% \times \text{уровень Эффективности}$ (или $100\%$ при атаке со спринта).
  - Починка любыми деревянными досками (`plankWood`) на наковальне.
  - Перенос узоров с флагов (Banners) на щит в верстаке с сохранением исходного флага.
  - Аутентичная 3D-модель (пластина и рукоять), 2D спрайт в инвентаре и звуковые эффекты блокирования.
  - Приоритетная поддержка второй руки (**Backhand**) — автоматическое размещение щита в оффхенд по ПКМ.

- 🔮 **Зачарования 1.9+ (Enchantments):**
  - 🗡️ **Разящий клинок (Sweeping Edge I-III):** увеличивает урон размашистой атаки до $50\% / 67\% / 75\%$ от базового урона меча. Настраиваемый ID с автоматическим обнаружением коллизий и сообщением в игровой чат.
  - ✨ **Починка (Mending):** сокровищное зачарование (сокровищницы, рыбалка, торговля), восстанавливающее прочность экипированных поврежденных предметов за счет сфер опыта (2 единицы прочности за 1 XP). Защита от конфликтов ID.

- 🍖 **Баланс сытости и регенерация 1.9+ (Rapid Health Regeneration):**
  - Быстрое восстановление здоровья: $1$ HP каждые $10$ тиков ($0.5$ сек), расходуя насыщение при максимальном уровне голода ($20$).
  - Стандартное восстановление: $1$ HP каждые $80$ тиков при сытости $\ge 18$.

- ⚖️ **Ребаланс боевой системы 1.9+:**
  - Обновленная система брони: внедрен показатель твердости брони (Armor Toughness), снижающий пробитие защиты мощными ударами.
  - Перебалансировка зачарования «Острота» (Sharpness): $+1.0$ урона на первом уровне и $+0.5$ за каждый последующий.
  - Перебалансировка зачарования «Защита» (Protection) по формулам 1.9+.
  - Отключено ванильное блокирование мечом на ПКМ в пользу щитов.
  - Поддержка экипировки из незерита (Netherite) из Et Futurum Requiem.

- 💥 **Масштабирование урона и отбрасывания (Damage & Knockback Scaling):**
  - При неполной зарядке атаки урон уменьшается по формуле 1.9+: `Damage * (0.2 + charge^2 * 0.8)`.
  - При неполной зарядке отбрасывание минимизируется (`0.1x`), а критические удары отменяются.
  - При полной зарядке ($charge \ge 0.9$) наносится 100% урона, стандартное/спринт-отбрасывание и возможность нанесения критов.

- 💨 **Размашистый удар (Sweep Attack):**
  - Наносится мечами при полной зарядке ($charge > 0.9$), стоя на земле и не в спринте.
  - Наносит сплэш-урон ($1.0$ урона / полсердца + зачарования) по всем окружающим врагам в радиусе $1.0$ блока от основной цели.
  - Отбрасывает задетых мобов в сторону от игрока.
  - Сопровождается оригинальным покадровым визуальным эффектом размашистого удара (8 кадров sweep FX из ванильных ассетов Mojang 1.9+) и аутентичными звуками (`player.attack.sweep`).

- 🗡️ **Анимация подъема оружия от первого лица:**
  - Плавный подъем руки и удерживаемого оружия/предмета снизу вверх при перезарядке атаки с квадратичной кривой интерполяции, идентичной ванильной 1.9+.

- 🎯 **Индикатор атаки (Attack Indicator):**
  - Использование аутентичных текстур Mojang для шкал и индикаторов.
  - Поддержка двух режимов отображения: **Crosshair** (под прицелом с индикатором `+` при наведении на цель) и **Hotbar** (справа от панели быстрого доступа), а также **Disabled**.
  - **Корректная работа с F1:** при скрытии интерфейса клавишей F1 индикатор автоматически скрывается.
  - Интеграция с графическим меню **Angelica** (раздел настроек видео) для переключения индикатора на лету.

## 🧩 Совместимость и внешние зависимости (Compatibility)

Мод спроектирован с учетом максимальной совместимости с популярными оптимизационными и геймплейными модами для 1.7.10 от сообщества [GTNewHorizons](https://github.com/GTNewHorizons):

| Мод | Статус | Назначение и интеграция |
| :--- | :--- | :--- |
| [**UniMixins**](https://github.com/GTNewHorizons/UniMixins) | **Обязателен** | Базовая система миксинов (Mixin 0.8.7) для внедрения боевой логики в Forge 1.7.10. |
| [**Backhand**](https://github.com/GTNewHorizons/Backhand) | **Крайне рекомендуется** (опционально) | Полноценный бэкпорт второй руки (offhand) для 1.7.10. Приоритетное использование щита в левой руке и боевая синхронизация. |
| [**Angelica**](https://github.com/GTNewHorizons/Angelica) | **Крайне рекомендуется** (опционально) | Современный графический движок (бэкпорт Sodium / Iris). Combat Backport бесшовно интегрирует кнопку переключения индикатора атаки прямо в интерфейс видеонастроек Angelica. |
| [**Et Futurum Requiem**](https://github.com/GTNewHorizons/Et-Futurum-Requiem) | Совместим (мягкая интеграция) | Автоматическое отключение дублирующихся компонентов (дедупликация Mending), балансировка незеритовой брони и инструментов. |
| [**Not Enough Items (NEI)**](https://github.com/GTNewHorizons/NotEnoughItems) | Совместим (мягкая интеграция) | Рецепт декорирования щита флагами в сетке крафта NEI. |
| [**NEI Integration**](https://github.com/GTNewHorizons/NEI-Integration) | Совместим (мягкая интеграция) | Интеграция рецептов сторонних модификаций в NEI. |
| [**Village Names**](https://github.com/GTNewHorizons/VillageNames) | Совместим | Полная совместимость без конфликтов генерации и интерфейсов. |
| [**lwjgl3ify**](https://github.com/GTNewHorizons/lwjgl3ify) | **Рекомендуется** (опционально) | Модернизированный бэкенд LWJGL 3, обеспечивающий «сырой» ввод мыши (raw input), поддержку дисплеев с высокой частотой обновления и повышенную плавность боя. |
| [**Tinkers' Construct (TiC)**](https://github.com/GTNewHorizons/TinkersConstruct) | Поддерживается | Автоматический расчет характеристик скорости атаки и урона для модифицированного оружия. |
| [**Hodgepodge**](https://github.com/GTNewHorizons/Hodgepodge) & [**GTNHLib**](https://github.com/GTNewHorizons/GTNHLib) | Поддерживается | Исправления ванильных багов, оптимизация рендеринга и системных вызовов. |

> [!IMPORTANT]
> **Папка `libs/` для сборки и компиляции (Compile-time dependencies):**  
> Бинарные dev-сборки сторонних модов не хранятся в репозитории и исключены из Git (`.gitignore`). Для компиляции мода из исходного кода (`./gradlew build`) или запуска тестового клиента (`./gradlew runClient`) поместите dev-jar файлы необходимых модов (собранные из соответствующих репозиториев [GTNewHorizons](https://github.com/GTNewHorizons) по ссылкам выше) в локальную папку `libs/`.

> [!NOTE]
> Моды **Angelica** и **Backhand** не являются строго обязательными для запуска: Combat Backport полностью функционален и на чистом Forge 1.7.10, однако их установка крайне рекомендуется для наилучшего визуального и игрового опыта.

## ⚙️ Конфигурация (`config/combatbackport.cfg`)

| Параметр | Категория | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `attackIndicatorMode` | `client` | `CROSSHAIR` | Режим индикатора: `CROSSHAIR`, `HOTBAR`, `DISABLED` |
| `enableItemReequipAnimation` | `client` | `true` | Анимация подъема оружия/предмета снизу вверх при перезарядке атаки |
| `enableAttackCooldown` | `combat` | `true` | Включение механики кулдауна атак |
| `enableSweepAttack` | `combat` | `true` | Включение размашистого сплэш-удара для мечей |
| `enableDamageScaling` | `combat` | `true` | Масштабирование урона в зависимости от готовности удара |
| `enableKnockbackScaling` | `combat` | `true` | Подавление отбрасывания при неполной зарядке |
| `enableAirSwingCooldown` | `combat` | `true` | Сброс кулдауна при ударе по воздуху (промахе) |
| `enableItemSwitchCooldown` | `combat` | `true` | Сброс кулдауна при смене слота хотбара |
| `customWeaponSpeeds` | `weapons` | `[]` | Пользовательские скорости оружия (`modid:item_name=speed`) |
| `customWeaponDamages` | `weapons` | `[]` | Пользовательский базовый урон (`modid:item_name=damage`) |
| `customSweepItems` | `weapons` | `[]` | Принудительное включение sweep-атаки для предметов (`modid:item_name`) |

---

## 🛠️ Сборка и запуск

```bash
# 1. Поместите dev-jar зависимости в папку libs/ (см. раздел Совместимость)
./gradlew setupDecompWorkspace # Подготовка рабочего пространства
./gradlew runClient           # Запуск клиента для тестирования
./gradlew build               # Сборка готового мода
./gradlew spotlessApply       # Автоматическое форматирование кода
```
